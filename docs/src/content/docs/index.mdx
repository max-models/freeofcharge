## What is included

<CardGrid>
	<Card title="Equilibria" icon="open-book">
		The flux from G-EQDSK files or the Solov'ev solution, flux surfaces, shell volumes, boundary and wall.
	</Card>
	<Card title="Beam deposition" icon="rocket">
		Markers on straight lines with Suzuki's stopping cross sections: birth profiles, fast-ion births and shine-through.
	</Card>
	<Card title="Slowing down" icon="document">
		Classical slowing down per flux surface: electron and ion heating, fast-ion pressure and the beam-driven current.
	</Card>
	<Card title="CPU, GPU, MPI" icon="setting">
		Arrays on the cunumpy backend; markers split over MPI ranks, profiles summed once.
	</Card>
</CardGrid>
